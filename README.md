# Proiecte facultate
Colecție de lucrări realizate la seminarele și cursurile din facultate, în domeniul administrației și al studiilor europene.

Managementul proiectelor: cerere de finanțare
Project Cycle Management: anexele unei cereri de finanțare (analiza problemei, a obiectivelor, a stakeholderilor, a strategiilor și Logical Framework)
Contabilitate: bilanț contabil realizat pornind de la o balanță fictivă, cu politicile contabile aferente
Uniunea Europeană: referate și prezentări despre Consiliul European, Comisia Europeană, guvernanța UE, neofuncționalism și interguvernamentalism
Metodologia cercetării: interviu nestructurat, observație participativă, analiză culturală
Politici publice și drept administrativ: proiecte și prezentări pe aceste teme
Istorie și cultură: lucrări despre comunismul lui Ceaușescu și despre Regina Elisabeta
